# Lunex OPS

Official website for **Lunex OPS**, a digital development studio building high-performance websites and custom web applications for businesses and startups.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- Lucide React

## Pages

- `/` — Home
- `/services` — Services
- `/work` — Selected Work
- `/about` — About Lunex OPS
- `/contact` — Start a Project

## Getting Started

```bash
npm install
npm run dev
```
